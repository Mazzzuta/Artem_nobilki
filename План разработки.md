## Зафиксированные пожелания пользователя к интерфейсу

- Все денежные значения отображать с ДВУМЯ знаками после запятой. Внутреннюю точность вычислений не уменьшать.
- Если заметка пустая, не показывать ни подпись, ни заглушку, ни лишнюю пустую строку.
- Три темы: Светлая, Тёмная, Системная. Выбор сохраняется; Системная следует Android. Старый двухрежимный переключатель мигрирует без потери выбора.
- Все выпадающие списки должны выглядеть одинаково: единый `DropdownSpinner`, ширина до 200 dp для обычных списков и до 320 dp для валют, строки от 56 dp (80 dp для валют с названием), разделители, максимум четыре полных видимых строки с прокруткой остальных; отступы внутри строк по 20 dp сверху и снизу. Валютные списки содержат код и русское название, поле поиска по коду/названию с учётом регистра и е/ё. Это относится к валютам, темам, категориям, сортировке и периодам.
- Записи, история и смысловые разделы отделены карточками с рамкой и скруглением. Поля экрана 24 dp, внутри карточек 20 dp, интервалы между разделами 20–24 dp.
- Нижний поясняющий текст и версия удалены из настроек; не возвращать без запроса.
- Нижнее меню: Избранное — звезда, Валюты — доллар, Конвертер — стрелки обмена, Аналитика — график, Настройки — шестерёнка.
- Все невыбранные иконки и подписи имеют общий tint; выбранный пункт выделен отдельно. Непрозрачные векторные иконки заменили старые системные с разной яркостью. Цвет невыбранных иконок дополнительно сравнен по скриншоту.
- Подписи ВСЕХ пяти вкладок всегда видимы (`labelVisibilityMode=labeled`).
- Статистика под графиком разнесена на строки внутри отдельной карточки. Правая и левая даты полностью помещаются в график (`avoidFirstLastClipping` и отступы).
- Нажатие на точку графика показывает дату и исходный курс с двумя знаками в подсказке; подсказка ограничена границами графика. Проверены вершина и крайняя правая точка.

## Текущее устройство приложения

- Пять основных вкладок плюс отдельные форма и карточка пары. Навигация через нижнее меню и Fragment back stack.
- Главная сущность — избранная валютная пара: название, две валюты, сумма по умолчанию, заметка, дата создания, несколько категорий.
- Полный CRUD через интерфейс, подтверждение удаления, валидация, поиск по названию/заметке/кодам, совместные фильтры по категории и дате (7/30 дней/всё время), сортировка по названию/дате.
- Категории создаются и удаляются с подтверждением; удаление категории убирает связи, сохраняя пары и историю.
- Курсы — официальный XML API Банка России: `https://www.cbr.ru/scripts/XML_daily.asp`, история — `XML_dynamic.asp`. Ключ API не требуется.
- Хранимый `currentRate` всегда RUB за ОДНУ единицу валюты: значение ЦБ делится на номинал при разборе. RUB=1. Формула: сумма × курс исходной / курс целевой.
- Разбор XML Pull Parser учитывает Windows-1251, номинал и дату; DTD/нестандартные сущности запрещены. DOM-парсер с неподдерживаемой Android настройкой удалён.
- Room v2: валюты, категории, история, старые связи валют и категорий, избранные пары, связи пар и категорий, исторические точки курса. Связь пара → история с SET NULL при удалении пары; пары ↔ категории через таблицу с CASCADE.
- Миграция 1→2 сохраняет старые данные. Старые котировки Frankfurter помечены `LEGACY` и не смешиваются с ЦБ. Обновление курсов через Upsert сохраняет связи.
- Конвертер работает по локальным котировкам, сохраняет историю с курсом и датой, не смешивает разные даты котировок. Последние 20 операций показаны карточками; статистика считает все.
- Аналитика: MPAndroidChart v3.1.0, столбцы количества конвертаций по направлениям и исторический график курса ЦБ за 7/30/365 дней. Все значения реальные, демонстрационный график удалён.
- Настройки: локальный личный кабинет (ФИО, дата рождения, неизменная дата регистрации), тема, базовая валюта отображения и сортировка; SharedPreferences.
- Экраны разделены карточками; списки имеют сворачиваемую шапку AppBarLayout/CoordinatorLayout, чтобы контент можно было прокручивать и на низком экране.
