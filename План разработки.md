## Что уже есть

- Kotlin, XML-разметка, ViewBinding, minSdk 24, compileSdk/targetSdk 34, Java 17.
- Пять вкладок: HomeFragment, CurrenciesFragment, ConverterFragment, AnalyticsFragment, SettingsFragment.
- Архитектура: Fragment → ViewModel → CurrencyRepository → Room / Retrofit, корутины и Flow.
- Room v1: CurrencyEntity, CategoryEntity, ConversionHistoryEntity, CurrencyCategoryCrossRef.
- Связующая таблица валют и категорий имеет внешние ключи с CASCADE; история конвертаций внешних ключей не имеет.
- Сетевой источник: https://api.frankfurter.app/; курсы сохраняются в Room, при сетевой ошибке предусмотрено чтение кэша.
- Поиск валют подключён; сортировка подготовлена во ViewModel, но управления в интерфейсе нет.
- Конвертер рассчитывает результат, но не сохраняет историю.
- AnalyticsFragment строит искусственные точки и условные минимум/максимум. AnalyticsViewModel с запросом истории к экрану не подключён.
- Настройки пока являются заготовкой: тема и очистка кэша показывают Toast, базовая валюта не применяется и не сохраняется.
- На главной есть RecyclerView популярных направлений, но его наполнение не подключено.
- Тесты шаблонные, предметную логику не проверяют.

## Обязательные требования к приложению

- Минимум пять экранов, включая список с поиском и добавлением, форму добавления/редактирования, детальный просмотр, аналитику и настройки.
- Полный CRUD главной пользовательской сущности через интерфейс.
- Минимум три основные таблицы и одна промежуточная; связи один-ко-многим и многие-ко-многим с явными внешними ключами.
- Поиск, два совместно работающих фильтра, сортировка.
- Аналитика реальных данных пользователя: минимум одна круговая или столбчатая диаграмма через библиотеку и числовые показатели.
- Минимум три работающие настройки.
- Валидация с выделением ошибочных полей и сообщением, подтверждение удаления, пустые состояния, индикаторы загрузки, обработка ошибок сохранения, офлайн-режим при использовании API.
- Разделение UI и логики, понятные английские имена, фоновые операции с БД.
- Одна органичная дополнительная функция. Для темы указаны конвертер с сохранением избранных пар и рекомендованная изюминка «API ЦБ, график курса».

## Известные риски

- AppDatabase использует fallbackToDestructiveMigration(): при изменении версии схемы без миграции возможна потеря данных.
- CurrencyDao обновляет курсы через INSERT REPLACE; при существующих каскадных связях замена строки может удалять связи. При доработке обновления курсов проверить и устранить этот риск.
- Текущая аналитика демонстрационная и не может считаться выполненным требованием.
- Работоспособность текущего API и наличие нужных валют не проверены.
- Пять вкладок сами по себе не закрывают требование к назначению пяти обязательных экранов.
